# GW2 Raid Selector 0.1.0.6

Nexus-only addon release

## Changes
# 0.1.0.0
- Initial version with raid and strike encounter selection and a daily encounter list
# 0.1.0.1
- Added map IDs for raid and strike encounters
- Added or adjusted map checks and status timeouts
# 0.1.0.2
- bugfixes
# 0.1.0.3
- Added encounter and wing images, favorites, and image hide options
- Optimized image assets to reduce build size
# 0.1.0.4
- Added a settings option to hide the search field
- Moved settings into a tab
- Grouped wings under raid and made them collapsible
- Added separate normal and hover icons
# 0.1.0.5
- Added automatic opening on first load or after an update
- Added an option to open after the final boss
- Added quick access icon visibility options for always or only in instances
# 0.1.0.6
- 2026-11-10 fix
# 0.1.0.7
- Added a restriction outside known raid and strike maps
